# Mobile Programming Practicum

This repository contains assignments, codelabs, and projects for the **Mobile Programming Practicum** course. The projects are built using [React Native](https://reactnative.dev/) and [Expo](https://expo.dev/) with TypeScript.

## Repository Structure

```text
.
├── Codelab 1/
│   └── Codelab/        # Module 1: Introduction to React Native, Expo & TypeScript exercises
├── Codelab 2/
│   ├── codelab1/       # Module 2 (Part 1): Basic UI Components & Layouts
│   └── codelab2/       # Module 2 (Part 2): Reusable Components & Styling
├── .gitignore
├── LICENSE
└── README.md
```

## Prerequisites

- [Node.js](https://nodejs.org/) (LTS recommended)
- [npm](https://www.npmjs.com/) or [Yarn](https://yarnpkg.com/)
- [Expo Go](https://expo.dev/go) app on your iOS or Android device (or an iOS Simulator / Android Emulator)

## Getting Started

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Frdalf/Mobile-Programming.git
   cd Mobile-Programming
   ```

2. **Navigate to a specific project directory:**

   ```bash
   # Example: Codelab 1
   cd "Codelab 1/Codelab"
   ```

3. **Install dependencies:**

   ```bash
   npm install
   ```

4. **Start the Expo development server:**

   ```bash
   npx expo start
   ```

   Scan the QR code using the **Expo Go** app (Android) or the Camera app (iOS), or press `a` for Android Emulator / `i` for iOS Simulator / `w` for Web.
